# Hardware Hello

面向软件工程师的 ESP32 多功能调试器入门书。

在线阅读：GitHub Pages 部署后见仓库首页。

本仓库只包含教程书稿、实践代码片段和静态阅读站点，不包含原项目源码副本或无关资料。

## 内容

- `book.md`：完整中文教程
- `index.html`：GitHub Pages 阅读站点
- `examples/`：从零开始的练习代码
- `docs/source-map.md`：原项目与本书章节的对应关系

## 适用读者

会写一种高级语言，理解 Git、命令行和基本调试，不要求有嵌入式经验。
